# 核查来源

1. 写清读者要判断的问题与研究边界。固定版本、运行条件和资料范围。源码给完整 SHA、文件和行号；外部文档给精确版本。未知条件保留未知。
2. 从实际入口追一条有代表性的路径。记录发起者、每步输入与输出、做决定的位置、状态或证据交给谁、结果由谁消费。沿同一例子改变一个条件，核对分支、拒绝、回退或实际停止行为。
3. 将主张和依据写入现有 Case/source map。对每条核心主张记录 `claim / scope / basis / source / check`；有必要时加上推导、测量方法、局限和可推翻条件。Case 可使用自己的结构。
4. 区分源码推导 `source-derived`、作者报告 `reported`、本地复现 `reproduced`、推断 `inferred` 和未知 `unknown`。比较结果时写明输入、环境、基线与指标；结论限于证据覆盖的条件。

交付一条能复查的路径及关键证据。领域条件由所选领域 skill 补充，讲解和图示引用这些事实。
