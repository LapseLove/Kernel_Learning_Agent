# Runtime 集成

1. 分别解释组件存在的理由和接入宿主的理由。交代宿主原有职责、组件新增能力、兼容条件与集成成本。
2. 画出生命周期。区分插件发现与注册、配置选路、资源准备、首次绑定或重绑、每轮执行。核实谁拥有缓存和缓冲，谁持有或借用地址，何时允许复用或释放。
3. 用同一轮请求追调度、分组、输入转交、执行和结果消费。写明请求顺序、区间与输出落点。若跨队列，标出谁记录、谁等待、等待后可读写什么；箭头表达依赖次序。
4. 让读者预测改变一个条件后的路径，例如没有 prefill、缓存句柄变化或超出容量。比较性能时只在明确的 workload 与基线内讨论吞吐、延迟、资源或兼容代价。
